# Bundled filter lists

These are snapshots taken from the `data/` folder of Brave's adblock-rust repository. Each list keeps its own licence; the
lists are data that is read by the ad blocker, they are not linked into Null Browser's code.

| File | Source | Licence |
|---|---|---|
| easylist.txt, easyprivacy.txt | https://easylist.to | GPLv3 / CC BY-SA 3.0 |
| ubo-*.txt | https://github.com/uBlockOrigin/uAssets | GPLv3 |
| brave-main-list.txt, brave-unbreak.txt, coin-miners.txt, brave-resources.json | https://github.com/brave/adblock-lists, brave-core | MPL-2.0 / see upstream |

Lists marked "updatable" in Settings -> Privacy and security -> Filter lists are re-downloaded from their original address
into your profile folder; the bundled copy is never modified.
